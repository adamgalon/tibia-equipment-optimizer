# Tibia Equipment Optimizer

A free web app for [Tibia](https://www.tibia.com) players to compare equipment and, step by step, plan gear for more damage, more experience and loot, and fewer deaths. English and Polish.

**Live site:** https://adamgalon.github.io/tibia-equipment-optimizer/

## What it does today (steps 1–5)

- Browse all ~1,600 wearable items: helmets, armors, legs, boots, amulets, rings, weapons (including Monk fist weapons), shields, spellbooks, quivers and ammunition.
- Filter by vocation, slot, your level and elemental protection; sort by level, armor, defense, attack or protection.
- Open any weapon's Weapon Proficiency perks in the list, or compare weapons by perks.
- Hide the sections you are not using; the page remembers.
- Compare up to 4 items side by side. The best value in each row is highlighted, with the difference to the first item. Comparisons are kept in the URL, so you can share a link.
- Build editor (step 2): pick an item for each of the 10 slots, set its forge tier and imbuements, and see total armor, skills, protections and forge effect chances. Choose Weapon Proficiency perks for the weapon. Two-handed weapons take the shield off, and mixed-vocation builds get a warning. Builds are saved in your browser and can be shared by link.
- Hunt advisor (step 3): pick the creatures you hunt and see their hardest hits per element and how much your build blocks, which element to attack them with, and the top 3 items per slot for that damage mix, with a button to wear each one.
- Prices (step 4): optionally load community prices for your world, type your own ("30kk"), see your build's value and the upgrades that add the most protection per gold within a budget.
- Look up your character to set vocation and level. Enter kills per hour, bonuses (stamina, XP Boost, prey, boosted creature) and supplies to see experience, loot and profit per hour.
- Optimize your build for a hunt in one click, within a budget if you like.
- Experience and loot (step 5): load a hunting place to fill in its creatures and see the wiki's ratings and recommended levels, plus each creature's experience and average loot value per kill from TibiaWiki's loot statistics.

## Development

Requires Node.js 24 or newer.

```bash
npm install
npm run dev            # local dev server
npm test               # unit tests
npm run test:e2e       # browser smoke tests on the production build (run npm run build first)
npm run build          # typecheck + production build into dist/
npm run import:items   # refresh the item, imbuement, creature and hunting place data from TibiaWiki (~4 minutes)
```

`data/items.json`, `data/imbuements.json`, `data/creatures.json`, `data/hunts.json` and `data/proficiency.json` are generated by `scripts/import-items.ts`. Do not edit them by hand. A GitHub Action refreshes them every Monday and commits only when something changed, so git history doubles as the record of changes.

Each data commit lists exactly what changed (`scripts/summarize-changes.ts`, also shown in the Action's run summary). If the repository has an `ANTHROPIC_API_KEY` secret, Claude (`claude-opus-5-5`) adds a short note on top that leads with what matters to players; without the secret, or if the call fails, the commit carries the list alone. `node scripts/summarize-changes.ts HEAD~1` shows the same list locally.
